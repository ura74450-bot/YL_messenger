# YL Messenger v3

## Что обновлено
- Надёжное хранение данных через PostgreSQL на Render вместо `data.json`.
- WebSocket с heartbeat и увеличивающейся задержкой переподключения.
- Web Push уведомления для сообщений, когда чат не открыт.
- PWA: `manifest.webmanifest` + `sw.js`, можно установить как приложение.
- Health-check `/api/health`.
- Ограничение размера запросов и базовые security-заголовки.
- REST остаётся резервным каналом сохранения сообщений.

## Render: обязательно
Подключи к Web Service базу **Render Postgres** и убедись, что у сервиса появилась переменная `DATABASE_URL`. Без неё Render-файлы остаются временными и сообщения могут пропадать после перезапуска.

Для Push создай три Environment Variables:
- `VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`
- `VAPID_SUBJECT` — например `mailto:your-email@example.com`

Ключи можно получить после установки зависимостей командой:
`npx web-push generate-vapid-keys`

После добавления переменных сделай **Manual Deploy → Deploy latest commit**.

## Важно про бесплатный Render
Бесплатный Web Service может засыпать после периода без входящего трафика, а бесплатный Render Postgres сейчас ограничен 30 днями. Для постоянного мессенджера база должна оставаться действующей.

## Уведомления
1. Открой мессенджер по HTTPS.
2. Открой Профиль → Уведомления.
3. Нажми на строку и разреши уведомления.
4. Для iPhone/iPad сначала добавь сайт на экран «Домой», затем разреши уведомления.
